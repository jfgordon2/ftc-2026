What each diagnosis word asks for

Symptom
The exact wrong result you can observe, such as a message, value, sound, or movement.
Hypothesis
One possible reason for the symptom that a check can support or reject.
Evidence
A message, file and line, telemetry value, log entry, measurement, or inspection result that supports what you say happened.
Cause
The reason the symptom occurred, confirmed by evidence rather than guessed.
Fix
The smallest change that corrects the confirmed cause.
Retest
Repeat the same check after the fix so the before-and-after results can be compared.

Change only one thing before each retest. If several things change together, the team cannot tell which change affected the result.
