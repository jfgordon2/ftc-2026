Today’s goal

Leave with a one-page troubleshooting guide made only from fixes this team has actually done, and a robot that works after every one of them.

At an event there are a few minutes between matches. The teams that recover are the ones that have seen the problem before. Today the mentor causes common problems one at a time. You find each one, fix it, and then run the robot again to prove it.

Start here

  1. Check the robot works before anything is broken. Baseline run.
  2. Drill: one planted problem at a time. Fault drills.
  3. Write the troubleshooting guide. Guide steps.
  4. Save. Save your work.

Before power

  • Cables are unplugged and plugged in only with the robot switched off.
  • A drill that could make the robot move unexpectedly is done on blocks.
  • One student drives. A different student keeps a hand near Stop on the Driver Station and may press it at any time without asking.
  • Press Stop and wait for everything to stop moving before you touch, load, measure or pick up the robot.
  • Clear a jam only with the robot switched off.
Stop first: if the robot goes the wrong way, something is loose, a ball jams, or the numbers on the screen look wrong, press Stop. Then work out why.

Steps and worksheets

Check it works first

  1. Run the TeleOp routine from Meeting 8 once.
  2. Run the team’s autonomous once.
  3. If either one fails, that is the first fault to find. Do not plant new ones on top of it.

Run Self-Inspect on the Driver Station (menu, Self-Inspect). Every line should be green. Inspectors at an event look at this screen.

Fault drills

One pair leaves the room. The mentor sets up one problem. The pair comes back and uses the five steps from Meeting 7: observe, guess, check, change one thing, conclude. A third student times them.

BatteryThe mentor fits a nearly flat battery.Slow launcher, “spin-up timeout”, sluggish driving.

A fix is not finished until the thing that failed has been run again and worked. If the autonomous failed, run the autonomous. If shooting failed, shoot.

Save your work

  • The troubleshooting guide lists only fixes the team actually did today.
  • Every fault you practiced has a line saying what fixed it and how long it took.
  • Real problems that are still open are in the fault log.
  • The working code is committed with a message you will recognize, for example “working before match practice”.

Meeting 15 runs full practice matches.

Mentor preparation

  1. Prepare the drills before students arrive and decide the order. Do one at a time and undo each before the next.
  2. Keep a flat battery aside for the battery drill and label it.
  3. Never plant a fault that could make the robot move unexpectedly or damage it. No shorted wires, no loosened wheels, no reversed motors on the floor.
  4. Print the robot test card and the worksheets with the page’s print button.
