Words you need before using them

Encoder velocity
The rotation rate reported by getVelocity(). With the pinned ticks-per-second overload, its unit is encoder ticks per second, not automatically RPM.
RPM
Revolutions per minute. Convert encoder velocity to RPM only after identifying documented encoder ticks per motor revolution and the complete motor-to-flywheel ratio. Source M12-F07
Surface speed
The distance traveled by the flywheel rim per unit time. It is flywheel circumference multiplied by flywheel revolutions per unit time. Source M12-F07
Artifact
The current game object used in the launch test. Record its exact type and measured size; do not assume every artifact is identical.
Launcher gap
The measured physical space between the flywheel contact surface and its opposing guide at the named contact location.
Compression
How much smaller the launcher gap is than the artifact's measured uncompressed size at the same reference. Compression percentage is that difference divided by artifact size, multiplied by 100. Source M12-F07
Spin-up time
Elapsed time from the launcher request until the ready condition first remains satisfied for the team's predeclared confirmation rule.
Recovery time
Elapsed time after an artifact passes until measured velocity again satisfies that same ready condition.
Transit or feed timing
Elapsed time from the feed request through the artifact's observed passage and the feed output's return to zero.
Ready condition
The branch-specific measured-velocity test that must pass before feed begins. A target request alone is not proof of readiness.
Abort
An immediate end to the attempt. Driver Station Stop is the required human abort; any separately implemented team abort signal must also route to the same explicit shutdown.
One-variable set
A baseline and comparison trials in which exactly one experimental variable changes while code identity, setup, artifact, battery criterion, feed behavior, and every other declared condition stay fixed.

Calculate and measure before changing code

Shared M12-M01 identity and roles for every record below

Use one unit system per calculation. Formula structure does not supply installed values: exact encoder and gearing values need matching documents, and all dimensions and times need current measurements.

  1. Convert encoder velocity to motor RPM: motor RPM = encoder ticks per second * 60 / documented encoder ticks per motor revolution. Source M12-F07 Record the exact motor/encoder document and API overload. Powered blocker: unknown ticks per revolution. Team choice M12-D01
  2. Convert motor RPM to flywheel RPM: flywheel RPM = motor RPM * flywheel revolutions per motor revolution. Source M12-F07 Trace every installed gear, belt, or chain stage and its direction. Powered blocker: an unverified assembled ratio. Team choice M12-D01
  3. Calculate flywheel surface speed: measure loaded flywheel diameter, calculate circumference = pi * diameter, then use surface speed = circumference * flywheel RPM / 60 for distance per second. Source M12-F07 Powered blocker: missing diameter, ratio, unit, or measurement method. Team choice M12-D01
  4. Measure physical launcher gap: with power disconnected and stored energy safe, name the contact reference and measure the gap at least three times without an artifact. Record the stated representative value and method.
  5. Measure the artifact: measure its uncompressed size at the matching contact orientation. Calculate compression = artifact size - launcher gap and compression percentage = compression / artifact size * 100. Source M12-F07 A negative or unexplained result is a powered blocker. Team choice M12-D01
  6. Measure timing: from telemetry and observation, record spin-up time, post-launch recovery time, and artifact transit or feed timing for every valid row. Never substitute the vendor timeout for one of these observed times.

Build one guarded action method

Copy no complete vendor method blindly. In a separately named candidate, adapt the matching path to the team's exact configured devices. The following is a teaching shape, not buildable robot code until every symbolic helper, output name, tested value, and source record is implemented for the matching branch.

enum LaunchResult { SUCCESS, NOT_READY, TIMEOUT, ABORTED, INACTIVE }

LaunchResult feedOneArtifactGuarded(double testedFeedSeconds,
                                    double testedTimeoutSeconds) {
    feedTimer.reset();
    if (abortRequested()) return LaunchResult.ABORTED;
    if (!opModeIsActive()) return LaunchResult.INACTIVE;
    if (timer.seconds() >= testedTimeoutSeconds) return LaunchResult.TIMEOUT;
    commandMatchingFeedOutputs();
    while (feedTimer.seconds() < testedFeedSeconds) {
        if (abortRequested()) return LaunchResult.ABORTED;
        if (!opModeIsActive()) return LaunchResult.INACTIVE;
        if (timer.seconds() >= testedTimeoutSeconds) return LaunchResult.TIMEOUT;

        telemetry.addData("Feed elapsed/bound", "%f / %f",
                feedTimer.seconds(), testedFeedSeconds);
        telemetry.addData("Action elapsed/deadline", "%f / %f",
                timer.seconds(), testedTimeoutSeconds);
        telemetry.addData("Feed abort requested", abortRequested());
        telemetry.update();
        idle();
    }

    if (abortRequested()) return LaunchResult.ABORTED;
    if (!opModeIsActive()) return LaunchResult.INACTIVE;
    if (timer.seconds() >= testedTimeoutSeconds) return LaunchResult.TIMEOUT;
    return LaunchResult.SUCCESS;
}

LaunchResult runGuardedLaunch(double targetVelocity,
                              double readyMinimum,
                              double readyMaximum,
                              double testedReadyDeadlineSeconds,
                              double testedMinimumSampleIntervalSeconds,
                              double testedReadyDurationSeconds,
                              int testedReadySamples,
                              double testedFeedSeconds,
                              double testedTimeoutSeconds) {
    LaunchResult result = LaunchResult.NOT_READY;
    int consecutiveReadySamples = 0;
    double readyStartSeconds = -1.0;
    double lastSampleSeconds = -testedMinimumSampleIntervalSeconds;
    timer.reset();

    zeroEveryTouchedOutput();
    try {
        if (abortRequested()) {
            result = LaunchResult.ABORTED;
            return result;
        }
        if (!opModeIsActive()) {
            result = LaunchResult.INACTIVE;
            return result;
        }

        launcher.setVelocity(targetVelocity);
        while (timer.seconds() < testedReadyDeadlineSeconds) {
            if (abortRequested()) {
                result = LaunchResult.ABORTED;
                return result;
            }
            if (!opModeIsActive()) {
                result = LaunchResult.INACTIVE;
                return result;
            }
            if (timer.seconds() >= testedTimeoutSeconds) {
                result = LaunchResult.TIMEOUT;
                return result;
            }

            double nowSeconds = timer.seconds();
            if (nowSeconds - lastSampleSeconds
                    < testedMinimumSampleIntervalSeconds) {
                // Yield once, then recheck every guard before considering a sample.
                idle();
                continue;
            }
            lastSampleSeconds = nowSeconds;

            double measuredVelocity = launcher.getVelocity();
            boolean readyNow = measuredVelocity >= readyMinimum
                    && measuredVelocity <= readyMaximum;
            if (readyNow) {
                if (consecutiveReadySamples == 0) {
                    readyStartSeconds = nowSeconds;
                }
                consecutiveReadySamples++;
            } else {
                consecutiveReadySamples = 0;
                readyStartSeconds = -1.0;
            }
            double readyElapsedSeconds = readyStartSeconds >= 0.0
                    ? nowSeconds - readyStartSeconds : 0.0;

            telemetry.addData("Target/measured", "%f / %f",
                    targetVelocity, measuredVelocity);
            telemetry.addData("Ready now", readyNow);
            telemetry.addData("Ready samples/required", "%d / %d",
                    consecutiveReadySamples, testedReadySamples);
            telemetry.addData("Minimum sample interval", "%f",
                    testedMinimumSampleIntervalSeconds);
            telemetry.addData("Ready elapsed/required", "%f / %f",
                    readyElapsedSeconds, testedReadyDurationSeconds);
            telemetry.addData("Ready deadline/action timeout", "%f / %f",
                    testedReadyDeadlineSeconds, testedTimeoutSeconds);
            telemetry.addData("Abort requested", abortRequested());
            telemetry.update();

            if (consecutiveReadySamples >= testedReadySamples
                    && readyElapsedSeconds >= testedReadyDurationSeconds) {
                result = feedOneArtifactGuarded(
                        testedFeedSeconds, testedTimeoutSeconds);
                return result;
            }
            idle();
        }

        result = timer.seconds() >= testedTimeoutSeconds
                ? LaunchResult.TIMEOUT : LaunchResult.NOT_READY;
        return result;
    } finally {
        // This expands to exactly one matching branch body shown below.
        zeroEveryTouchedOutput();
        telemetry.addData("Launch result", result);
        telemetry.addData("Every touched output zero", zeroReadbackSummary());
        telemetry.update();
    }
}

// REV matching body only:
void zeroEveryTouchedRevOutput() {
    flywheel.setVelocity(0.0);
    feederContinuousRotationServo.setPower(0.0);
    intake.setPower(0.0);
}

    windmill.setPower(0.0);
    intake.setPower(0.0);
    cornerIntakeLeft.setPower(0.0);
    cornerIntakeRight.setPower(0.0);

  1. Active check: opModeIsActive() must be true before and during action work; Driver Station Stop makes continued action ineligible.
  2. Timeout: use only the matching, reviewed bound. REV's example maximum is 15 seconds. The goBILDA TeleOp supplies no Autonomous timeout, so the team must measure, approve, and record a bounded value before enabling that adaptation.
  3. Ready condition: use the exact matching branch's baseline or bounded candidate. Require at least two consecutive qualifying velocity samples separated by the team's documented positive minimum sample interval, and require the ready range to remain satisfied for a documented positive minimum elapsed confirmation duration. The team must predeclare and test the interval, duration, sample count, and ready deadline. Reset both the count and confirmation start after any nonqualifying sample. Never feed merely because a tight loop counted repeated reads, the target was requested, or one sample crossed the threshold.
  4. Abort: the Stop owner presses Driver Station Stop for any stop condition. If a team-owned explicit abort signal is implemented, test it and route it through the same finally shutdown. ABORTED applies when that explicit request is observed; INACTIVE applies when the OpMode is no longer active before an explicit request is observed.
  5. Feed guard: check abortRequested(), opModeIsActive(), and the same tested action deadline immediately before commanding feed, continuously while feed is commanded, and immediately after the loop before reporting success. Do not command feed if any pre-command guard fails. The feed timing bound never overrides the action timeout.
  6. Distinct result: record NOT_READY when the separate ready deadline ends without enough consecutive samples, TIMEOUT when the overall tested timeout ends, ABORTED for an observed explicit abort, INACTIVE when the OpMode becomes inactive, and SUCCESS only after guarded feed completes.
  7. Telemetry: report target, measured velocity, current and required consecutive ready samples, minimum sample interval, current and required ready duration, ready deadline, action timeout, abort state, feed timing, distinct result, and named zero evidence.
  8. Shutdown: zeroEveryTouchedOutput() expands to exactly one displayed matching-vendor zero body and runs before action and in finally on success, inactive state, timeout, abort, not-ready exit, and early return.

Powered blocker: before enabling this method, require testedReadySamples >= 2, testedMinimumSampleIntervalSeconds > 0, testedReadyDurationSeconds > 0, 0 < testedReadyDurationSeconds < testedReadyDeadlineSeconds < testedTimeoutSeconds, and a positive tested feed bound that leaves time before the overall timeout. Missing or untested bounds block power. Use idle() to yield between interval-spaced samples; do not use a long blocking sleep that delays active, abort, or deadline checks. Team choice M12-D01

For the REV range, pass readyMinimum = targetVelocity - 50 and readyMaximum = targetVelocity + 50. For the matching goBILDA minimum-threshold behavior, implement a clearly reviewed one-sided ready helper rather than inventing a universal upper bound; the displayed two-bound shape must not create one.
